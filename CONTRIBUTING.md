# Contributing

Thanks for your interest. Before opening an issue or pull request, please read the
[development guide](docs/development.md), [security policy](SECURITY.md), and
[code of conduct](CODE_OF_CONDUCT.md).

## Issues

Include a minimal reproduction, expected vs. actual behaviour, your OS and
Python/Docker versions, and redacted logs. Do not include API tokens, signed URLs,
credentials, private paths, or copyrighted content.

## Pull requests

1. Branch from the latest default branch.
2. Add or update offline tests for observable behaviour.
3. Update affected documentation.
4. Run every check in the development guide.
5. Explain the motivation, design choices, verification, and compatibility impact.

Maintainers may ask to split large changes, add tests, or adjust docs before merging.
